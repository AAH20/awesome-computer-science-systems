# Human-Computer Interaction and Human Command

**Core question:** Can people understand, override and safely command increasingly complex automation?

**Claim boundary:** More alerts and faster clicks do not establish better decisions.

## Evaluation axes

- Critical miss rate
- Override latency
- Reviewer throughput
- Nasa-tlx workload
- Accessibility
