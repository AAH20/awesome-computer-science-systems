# Statistics, Machine Learning and Causal Science

**Core question:** Does a model improve independently accepted decisions beyond a simpler baseline?

**Claim boundary:** Prediction, intervention effects and generative plausibility are different claims.

## Evaluation axes

- Calibration
- Generalization
- Subgroup error
- Causal identification
- Cost per accepted decision
